# Privo — Client-Side Privacy Utility Suite

[Privo](https://privo.eu.org) — бесплатный набор веб-инструментов, ориентированный на полную конфиденциальность данных. Все операции выполняются исключительно на стороне клиента (в вашем браузере), без передачи информации на сторонние серверы.

## 🚀 Особенности

- **100% Client-Side Processing:** Данные не покидают ваш браузер. Zero-backend архитектура.
- **Полная приватность:** Никакого сбора персональных данных, трекинга или сохранения истории на сервере.
- **Мгновенная скорость:** Мощный клиентский стек обеспечивают максимальную производительность.
- **SEO & Open Graph:** Оптимизировано для поисковых систем и соцсетей.

## 🛠 Доступные инструменты

- **Compress Image:** Локальное сжатие и оптимизация изображений без потери качества.
- **Hash Generator:** Вычисление хэш-сумм (MD5, SHA-256, SHA-512) прямо в браузере.
- **Password Generator:** Генерация криптографически стойких паролей.
- **Text Encryptor:** Шифрование и расшифровка текстовых данных.

## 💻 Технологический стек

- **Core:** HTML5, CSS3, JavaScript / WebAssembly
- **Bundler:** Vite
- **Deployment:** Vercel
- **DNS & Security:** Cloudflare
